## What I've built

- **Self-landing model rocket**: two-axis thrust vector control gimbal, Teensy 4.1 flight computer with sensor fusion and PID control, LoRa telemetry. Designed, 3D-printed and ground-tested. [Project write-up (PDF)](https://mikamoenchmeier.com/self-landing-rockets.pdf)
- **Home server**: self-hosted Home Assistant, Nextcloud and a Paperless-ngx pipeline where an AI step reads, tags and files scanned letters automatically.
- **[CleanSwap](https://cleanswap.mikamoenchmeier.com)**: an iPhone app in Swift that reads the ingredients on personal-care products and explains what's in them. In development.
- **[This website](https://github.com/mikamoenchmeier/website)**: a three.js rocket tour on Cloudflare Workers, designed and directed by me, built with AI-assisted coding.
